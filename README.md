# Portfolio website

A responsive, static portfolio ready for GitHub Pages.

## Personalize it

Edit `index.html` and replace these placeholders:

- `Your Name` and `yourname.portfolio`
- `hello@yourname.com`
- `your city`
- GitHub and LinkedIn URLs
- the sample project titles and descriptions

## Publish with GitHub Pages

1. Create a new GitHub repository (for example, `portfolio`).
2. Upload the contents of this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will show the published URL after deployment.

For a site at `https://USERNAME.github.io`, name the repository `USERNAME.github.io`.
